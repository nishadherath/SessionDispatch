### Adversarial pass

The opposite verdict, argued: continue. The stage is 15 turns of simple work; the context is 400,000 tokens, far under K (970,000), so no compaction risk. A handoff is work, a fresh session starts colder, and the operator has to click to start it and then give the approval inside it. Haiku also runs a release, and its tier price narrows the saving. Continuing keeps the same session that knows the project, and the operator's yes can be asked here at once.

Each input, the way it could be wrong:

- C0 (measured): if 30 percent lower (280,000), C_cont is 302,500 and cost_continue falls to 0.716 USD.
- T (estimated, 15): if it doubles to 30, continue rises faster than fresh (the cache-read gap grows), so fresh is favoured more.
- F and O (measured on a similar chore, effort unknown): if 50 percent larger, both sides rise; fresh keeps a large margin.
- B and R (measured and stated): if R were larger by 20,000, the fresh start is 114,450, the whole stage is at the tier; computed below.
- M: the operator approval pause is one cache miss in the worst case. Continue pays 1 x 422,500 x (2.5 - 0.1)/1e6 = 1.014 USD more; fresh pays about 116,950 x (0.625 - 0.05)/1e6 = 0.067 USD more. Fresh gains.
- Task type: if the patch hides a design choice, haiku is wrong and sonnet should run it (guardrail-free, the patch is described as reviewed).
- Prices: table 1 day old; haiku tier applied turn by turn as step 1.4.5 says.
- Unrecorded context: none claimed. The disk holds everything.

Recomputed with the adverse values that move the result most (two together: the stage runs on sonnet because the task hides a design choice, and C0 is 30 percent lower):

```
cost_continue (C0 280,000)   = 15*302,500*0.1/1e6 + 0.1125 + 0.15 = 0.45375 + 0.2625 = 0.71625 USD
cost_fresh at sonnet         = 0.025 + 94,450*2.5/1e6 (0.23613) + 15*116,950*0.1/1e6 (0.17543)
                               + 0.1125 + 0.15                     = 0.69905 USD
```
Sonnet alone with the measured C0 gives continue 0.89625 against fresh 0.69905, a 28 percent margin, so fresh still wins. With both adverse values together the gap is 0.017 USD (2.5 percent): inside the 10 percent band. Also the all-tier case for haiku (every turn at the tier): 0.025 + 0.059 + 0.0877 + 0.0281 + 0.0375 = 0.237 USD, still far below continue.

Verdict holds: yes, fragile: it flips to the quality terms only if the task needs sonnet and C0 is 30 percent lower together. Neither value is claimed to be true (C0 is measured, the task is described as a reviewed patch), so the verdict stays.
