### Step A: continue or hand off

```
G       = F + O                 = 3,000 + 3,000 = 6,000
C_end   = C0 + T * G            = 150,000 + 240,000 = 390,000 (below K 970,000)
crosses = C_end > K             = false
C_cont  = C0 + T * G / 2        = 150,000 + 120,000 = 270,000
C_fresh = B + R + T * G / 2     = 86,450 + 25,000 + 120,000 = 231,450

cost_continue (sonnet prices)
  = T*C_cont*p_cr + T*G*p_cw + T*O*p_out + M-term + penalty
  = 40 * 270,000 * 0.10/1e6 + 240,000 * 2.50/1e6 + 120,000 * 10/1e6 + 0 + 0
  = 1.08 + 0.60 + 1.20 = 2.88 USD

cost_fresh (opus prices, H at sonnet output rate)
  = H*p_out[sonnet] + (B+R)*p_cw + T*C_fresh*p_cr + T*G*p_cw + T*O*p_out + 0 + 0
  = 0.025 + 111,450 * 5.00/1e6 + 40 * 231,450 * 0.20/1e6 + 240,000 * 5.00/1e6 + 120,000 * 20/1e6
  = 0.025 + 0.557 + 1.852 + 1.200 + 2.400 = 6.03 USD

T* = n/a: the model changes (sonnet to opus), so the short-path break-even does not apply.

cost_split (sonnet run, opus acceptance) = 5.45 USD

  run at sonnet, without H                           0.279 + 0.926 + 0.600 + 1.200 = 3.004

  acceptance turns: Ta 15 at C_acc = 161,450, G, O   0.484 + 0.450 + 0.900 = 1.834
  total                                              5.446
```

### Adversarial pass

The opposite verdict, argued: continue. The session holds the whole design discussion and the reasons behind it. Continuing costs 2.88 USD against 6.03 for a fresh session, which is 109 percent cheaper. There is no compaction in sight (390,000 at the end, below 970,000), so the quality cost of staying is nil. A fresh opus session would also need to read 111,450 tokens before doing any work. Against that: the work is opus-class evaluation design, and continuing runs it at sonnet, which verdict rule 1 and guardrail 8 forbid.

Each input, the way it could be wrong:

- C0: measured at 150,000. If it were 30 percent higher (195,000), continue's cost rises by about 1.1 USD, and fresh's C_fresh is unchanged. Continue remains cheaper; the class verdict does not depend on cost.
- T: 40 is one value. If it doubles to 80, continue is 6.72 USD and fresh is 13.41 USD. Continue remains cheaper, and the verdict still turns on class.
- F and O: estimated. Writing-heavy O of 3,000 is plausibly 2,000 to 4,000 at high effort. Higher O raises fresh's opus output terms more than continue's sonnet terms, so the gap does not close.
- B and R: B is measured. R of 25,000 is a given figure. If R were 50,000, fresh rises by about 0.5 USD and continue is unchanged.
- M (review pauses): none expected. Each miss on fresh costs the opus cache-write rate over C_fresh, so review pauses would widen the gap against fresh.
- Task type: the stage is evaluation design, which the matrix puts at opus. If it were mechanical, the class verdict would change, but the situation names it as scenario and measure design, so the row stands.
- Prices: table 1 day old, Anthropic rows non-null, no long-context tier applies. Not binding.
- Unrecorded context: the situation says none. If some existed, L turns at the fresh average would add to fresh's cost and strengthen the continue side on cost, but the class rule still decides.
