### Step A: continue or hand off

```
G       = 3,800                                  (measured, F + visible output)
C_end   = 600,000 + 90 * 3,800          = 942,000
crosses = 942,000 > 970,000             = false  (28,000 tokens under K)
C_cont  = 600,000 + 90 * 3,800 / 2      = 771,000
C_fresh = 86,450 + 20,000 + 90 * 3,800 / 2 = 277,450

cost_continue (opus-5-5)
  reads   90 * 771,000 * 0.20 / 1e6     = 13.878
  writes  90 * 3,800   * 5.00 / 1e6     =  1.710
  output  90 * 3,000   * 20.00 / 1e6    =  5.400

  = 20.988 USD -> 20.99

cost_fresh (sonnet-5-5, H at opus output rate)
  H       2,500 * 20.00 / 1e6           =  0.050
  first   (86,450 + 20,000) * 2.50 / 1e6 =  0.266

  writes  90 * 3,800   * 2.50 / 1e6     =  0.855
```

### Adversarial pass

The opposite verdict, argued: continue. The stage is one module with a test oracle, so it does not need a colder start. The handoff is work (about 15 minutes of writing, committing and reading), and a fresh session re-reads 20,000 tokens the current one already holds. Continuing keeps the 600,000 tokens of context and avoids the operator's start step. The cost gap is in favour of fresh, so this case rests on quality, and the quality rule only applies inside the 10 percent band.

Each input, the way it could be wrong:

- C0: measured. At 30 percent off (780,000) the gap widens for continue. At 420,000 the break-even is about 5.0 turns, still under 90.
- T: 90 is a plan estimate. Doubled to 180, C_end is 1,284,000 and crosses K. Continue then costs about 48.3 USD, fresh about 15.5 USD. Fresh still wins by cost.
- F and O: measured at high effort. A doubled O (6,000) raises continue's output cost by 5.40 and fresh's by 2.70. The verdict holds.
- G: measured at 3,800. Had G been F + O (6,000), C_end would be 1,140,000 and the stage would cross K. Fresh would still win, and continue would add the compaction penalty.
- B and R: B is measured. R is a situation figure. Doubling R to 40,000 adds about 0.23 USD to fresh. The verdict holds.
- M (review pauses): none expected. Each miss costs about 3.70 USD on continue and about 0.67 USD on fresh, so any pause favours fresh.
- Task type: the stage is scoped, with a test oracle. If design choices appear, guardrail 2 applies only when the stage also crosses K, which it does not at T = 90. It crosses at about T = 98.
- Prices: table 1 day old; both rows read live on 2026-10-29. No long-context tier.
- Unrecorded context: the list is empty. If 10 turns of rediscovery were needed (L = 10), fresh rises by about 0.67 USD to 7.04 USD. Still far under continue.
