### Step A: continue or hand off

Hand arithmetic (prices per million: sonnet in 2, out 10, cache_read 0.1, cache_write 2.5; opus in 4, out 20, cache_read 0.2, cache_write 5).

```

crosses = C_end > K             = false (390,000 < 970,000)
C_cont  = C0 + T * G / 2        = 270,000
C_fresh = B + R + T * G / 2     = 111,450 + 120,000 = 231,450

              = 2.88 USD

                         + 240,000*5e-6 (1.2000) + 120,000*20e-6 (2.4000) + 0 + 0
```

### Adversarial pass

The opposite verdict, argued: continue costs 2.88 USD against 6.03, less than half, and the session already holds the project's context at 150,000 tokens with a 970,000 compaction point far away. A handoff is work, and a cold session starts without the session's feel for the project. Sonnet at medium could write the design and a later acceptance could catch the gaps. This fails on class: evaluation design is Opus work, and running it below its class is the error the matrix exists to prevent. All the needed knowledge is on disk, so the fresh session loses nothing.

- C0: measured. If 30 percent lower (105,000), continue gets cheaper still; the class rule still decides.

- F and O: unmeasured defaults. O is larger at high effort, which raises both sides and lifts the opus side more. The verdict is by class and does not move.

- Prices: table 1 day old; no long-context tier on either row, so none applied.
