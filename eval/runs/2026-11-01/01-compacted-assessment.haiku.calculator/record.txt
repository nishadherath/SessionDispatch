### Step A: continue or hand off

```
G       = F + O                 = 3,000 + 1,500 = 4,500
C_end   = C0 + T * G            = 100,000 + 270,000 = 370,000
crosses = C_end > K             = true (370,000 > 190,000)
C_cont  = C0 + T * G / 2        = 235,000
C_fresh = B + R + T * G / 2     = 25,000 + 30,000 + 135,000 = 190,000

cost_continue = T*C_cont*p_cr + T*G*p_cw + T*O*p_out + M*C_cont*(p_cw - p_cr) + penalty_compaction
              = 3.525 + 3.375 + 4.5 + 0 + 0.5 = 11.90 USD
cost_fresh    = H*p_out + (B+R)*p_cw + T*C_fresh*p_cr + T*G*p_cw + T*O*p_out + M*C_fresh*(p_cw - p_cr) + penalty_loss
              = 0.125 + 0.6875 + 2.85 + 3.375 + 4.5 + 0 + 0 = 11.54 USD
T* = (H*p_out + (B+R)*p_cw) / ((C0 - B - R) * p_cr) = 0.8125 / 0.01125 = 72.2 turns
cost_split    = H*p_out + run at sonnet + acceptance at opus (Ta, Ra)
              ≈ 0.125 + 2.85 + 1.21 = 4.19 USD (hand-computed, not in the draft verdict)
```

penalty_compaction (continue) = R*p_cw + H*p_out = 0.375 + 0.125 = 0.5 USD.

Prices used (per million): claude-fable-5-1 input 10, output 50, cache_read 0.25, cache_write 12.5.

The opposite verdict, argued: Continuing keeps the 100,000 tokens of context already built up, and the costs are close (11.90 against 11.54). The session has compacted only once and the context is still well inside the window. Rebuilding from a handoff risks the same rediscovery loss that continuing avoids, and the quality penalty of the compaction is not priced here.

Each input, the way it could be wrong:

- C0: the status line is approximate; a higher C0 widens the gap between the two sides and makes continue more expensive.
- T: 60 turns is a stage description; a longer stage pushes T past T* of 72.2 and favours continue on cost.
- F and O (and the effort O assumes): F at 5,000 to 8,000 raises G and both sides; O assumes high effort.
- B and R: B at 25,000 is an estimate; R is summed from per-file estimates.
- M (review pauses): none expected; any pause past the cache lifetime adds cache writes to both sides and to continue most.
- Task type: matrix row 6 is an assessment; a row 1 or 2 classification would change the split analysis.
- Prices: the table is 1 day old and the Fable row is complete.
- Unrecorded context: none listed. Any unrecorded context would add to L and to the fresh side.
