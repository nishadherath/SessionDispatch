### Adversarial pass

The opposite verdict, argued: Continue is 3.15 USD cheaper at the stated inputs, and the forecast context stays at 390,000 tokens, well under K (970,000), so no compaction is expected. A sonnet session already holds the 150,000-token context and the decisions in it, so a cold start loses the "why" and costs a handoff. The cost of continuing is that the design runs one class below its matrix row, which the matrix forbids for evaluation design, so the class rule decides.

Each input, the way it could be wrong:

- C0: measured. At 30 percent more (195,000), continue rises to 3.06 USD. Fresh is unchanged. Verdict holds.
- T: doubled to 80, continue is 6.72 USD and fresh 13.41 USD. Crosses stays false (630,000 under K). Fresh stays dearer; class rule holds.
- F and O: O at 6,000 (xhigh-style reasoning) gives continue 4.62 USD and fresh 9.51 USD. Fresh stays dearer; class rule holds.
- B and R: measured. Not changed by any tested value that moves the verdict.
- M (review pauses): each miss adds 0.65 USD to continue and 1.11 USD to fresh. The gap widens against fresh; class rule holds.
- Task type: the input that can flip the verdict. If the stage is really scoped module work (sonnet row), the class rule does not fire, and continue wins on cost at 2.88 USD against 6.03 USD. Recorded as fragile: flips at task type sonnet row.

- Unrecorded context: list is empty, L = 0. Any item found later would add to fresh cost only, so it strengthens continue on cost but not on class.
