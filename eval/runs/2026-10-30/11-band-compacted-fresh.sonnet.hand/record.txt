### Step A: continue or hand off

The calculator script is not in the skill folder, so this is computed by hand.

```
G       = F + O                 = 3,000 + 1,500 = 4,500
T*G                             = 45 x 4,500 = 202,500
C_end   = C0 + T * G            = 180,000 + 202,500 = 382,500
crosses = C_end > K             = 382,500 > 970,000 = false
C_cont  = C0 + T * G / 2        = 180,000 + 101,250 = 281,250
C_fresh = B + R + T * G / 2     = 86,450 + 15,000 + 101,250 = 202,700

Prices per token (sonnet): p_cr 0.1e-6, p_cw 2.5e-6, p_out 10e-6

cost_continue = T*C_cont*p_cr   = 45 x 281,250 = 12,656,250 tokens x 0.1e-6 = 1.265625
              + T*G*p_cw        = 202,500 x 2.5e-6 = 0.50625
              + T*O*p_out       = 67,500 x 10e-6 = 0.675
              + M term 0 + penalty_compaction 0 (crosses false)
              = 2.446875 USD  (2.45)
cost_fresh    = H*p_out         = 2,500 x 10e-6 = 0.025
              + (B+R)*p_cw      = 101,450 x 2.5e-6 = 0.253625
              + T*C_fresh*p_cr  = 45 x 202,700 = 9,121,500 x 0.1e-6 = 0.91215
              + T*G*p_cw        = 0.50625
              + T*O*p_out       = 0.675
              + M term 0 + penalty_loss 0 (L = 0)
              = 2.372025 USD  (2.37)
T* = (H*p_out + (B+R)*p_cw) / ((C0 - B - R) * p_cr)
   = (0.025 + 0.253625) / (78,550 x 0.1e-6) = 0.278625 / 0.007855 = 35.5 turns
     (formula holds for cost; the short path itself is closed because the session has compacted)
cost_split    = not computed: the target is below opus
```

Prices used (per million): claude-sonnet-5-5 input 2, output 10, cache_read 0.1, cache_write 2.5 (current and target are the same model; no long-context tier).

Cost difference: 2.446875 - 2.372025 = 0.07485 USD, 3.2 percent of the smaller (0.2372 is the 10 percent line). Costs are within 10 percent, so verdict rule 3 applies: the session has compacted once, so the quality terms decide against continuing.

Draft verdict: fresh, by quality, margin 0.07 USD (3.2 percent of the smaller, within the 10 percent band; fresh is also cheaper, and T 45 exceeds T* 35.5).

### Adversarial pass

The opposite verdict, argued: continuing avoids writing and committing a handoff, avoids a colder start, and needs no operator click. The cost gap is 0.07 USD, 3.2 percent. All the needed knowledge is already on disk, so the compaction's loss of "why" matters little here, and the context never nears K.

Each input, the way it could be wrong:

- C0: measured. If 30 percent lower (126,000), C0 - B - R = 24,550, T* = 113 turns and fresh would lose on cost; the verdict would then rest on quality alone, and the compacted rule still picks fresh.
- T: estimate. If it halves to 22, see the recomputation below. If it doubles to 90, fresh gains more.
- F and O: defaults, unmeasured. They cancel in the cost difference as the growth terms are equal on both sides; they only move the totals.
- B and R: B measured. R is the handoff plus the module as stated; if the module needs more files, R rises and fresh costs more. +20,000 on R adds about 0.05 USD to fresh and 0.09 USD to the per-turn read term, which could cross to continue only on cost, still inside the band.
- M (review pauses): none expected. One miss would add 0.63 USD to continue (281,250 x 2.25e-6) and 0.46 USD to fresh (202,700 x 2.25e-6), favouring fresh.
- Task type: a refactor with a test oracle is row 2; a hidden design choice would make it design-heavy and guardrail 2 would then force fresh anyway.
- Prices: table 1 day old, no long-context tier on Sonnet, no nulls.
- Unrecorded context: none per the situation; if some existed, L above 0 would add cost to fresh.
